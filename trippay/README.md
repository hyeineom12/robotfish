# TripFin — 소비 데이터 기반 그룹 여행 금융 서비스 (MVP)

2026 금융 AI Challenge 출품작 프로토타입.
개인·그룹의 카드 소비 패턴을 분석해 **여행 예산과 일정을 추천**하고, **여행 전–중–후 전 과정의 금융 활동**을 지원합니다.

## 실행 방법

```bash
npm install
npm run dev      # http://localhost:3000
```

프로덕션 빌드 / 배포:

```bash
npm run build && npm start
# 또는 Vercel에 이 폴더를 그대로 연결 (설정 불필요)
```

## 구현된 로직 (`src/lib/analysis.ts`)

MVP 단계이지만 핵심 계산은 실제 알고리즘으로 동작합니다.

- **소비 프로파일링** — 카테고리 지출 비중을 10차원 벡터로 만들고, 4개 클러스터 centroid와 **코사인 유사도**로 분류
- **예산 산정** — 유동자산 35%(비상금 보존) + 월 잉여금 가중 → 안전/최대 상한. 저축 추이로 "N개월 뒤 얼마까지" 타임라인 산출
- **그룹 예산** — 구성원 중 **여력이 가장 적은 사람 기준**으로 산정
- **여행지 랭킹** — 취향 적합도(55%) × 예산 부담도(45%) 가중 스코어
- **n빵 정산** — 채권/채무 상계로 **최소 송금 횟수** 계산
- **결제 룰렛** — 누적 결제 기여도가 적을수록 당첨 확률이 높아지는 **가중 룰렛**. 당첨자가 해당 결제를 **전액 부담(쏘기)** 하며 n빵 분할에서 제외
- **환율 비교** — 카드 해외수수료 vs 현금 환전 스프레드(1.75%) 비교
- **과소비 조기경보** — 일 권장 예산 대비 소진율 구간별 경고
- **프로파일 재학습** — 여행 중 지출을 소비 벡터에 15% 가중치로 병합 → 다음 추천 반영

## 2차 확장 예정

- 가맹점명 **텍스트 임베딩** 기반 세밀한 취향 추론 (프랜차이즈 vs 로컬 탐방형)
- **오토인코더 재구성 오차** 기반 실시간 이상소비 탐지
- LLM 일정 생성 API 연동 (현재는 `src/lib/itinerary.ts`의 규칙 기반 생성기 — 동일 인터페이스로 교체 가능)
- 네이버 지도/블로그 한국인 리뷰 실시간 큐레이션
- 소비 캐릭터 게임화 ("짠돌이형", "탕진잼형")

## UX 라이팅

토스 UX 라이팅 원칙을 따릅니다.

- 해요체로 통일하고, 사용자가 이해할 수 있는 말로 씁니다 (예: "안전 예산 상한" → "무리 없는 예산")
- 장식용 이모지를 쓰지 않습니다. 카테고리는 색상 점으로 구분합니다
- 버튼은 무슨 일이 일어나는지 알 수 있게 씁니다 (예: "확인" → "일정 확정하고 여행 시작하기")
- 이모지는 사람 아바타와 국가 국기처럼 정보를 담을 때만 씁니다

## 주의

모든 금융 데이터는 **데모용 가상 데이터**입니다. 실제 카드사·계좌 연동은 포함되어 있지 않습니다.
카드 상품명은 실제 국내 상품이지만 혜택 조건은 데모 기준값이며, 실제 조건은 카드사 안내를 따릅니다.
